# Brag Plan: openloop (5s YouTube opening)

## What is this app?
OpenCode plugin that enforces strong-model work discipline. Bottles the loop, not the brain.

## The angle
A channel ident that behaves like the product: no fluff, three rules, done in 5 seconds. Terminal honesty, not startup confetti.

## Hook (first 1.5 seconds)
Black screen. A mono cursor types `openloop` character by character with key ticks, then the word slams to full brightness. Viewer knows the name before second 2.

## Key moments (the middle)
- The 3 rules arrive one by one, each with a soft tick: `plan gate` → `skill-first` → `evidence`.
- Real product material: the exact rule words from AGENTS.md, set like terminal output.

## Outro / punchline
Lockup: giant `openloop` + small `github.com/bilhokista/openloop`. One dry impact hit. Cut to content.

## User flow worth showing
none — developer plugin, no app UI. Text-forward sequence carrying real copy.

## Tone
- Preset: cinematic (compressed to ident length)
- Creative direction: 5-second terminal ident
- Interpretation: big mono type, hard cuts, restrained sound. Confidence through brevity.

## Format: landscape — 1920x1080
## Duration: 5 seconds

## Visual identity (from the project)
- Background: #0a0a0f (near-black terminal)
- Accent: #4ade80 (terminal green)
- Text: #f5f5f5
- Display font: monospace (JetBrains Mono / ui-monospace fallback)
- Body font: same mono
- Strongest visual element: typed terminal line + rule list

## Share copy (draft)
openloop — work like Opus, on any model. 5-second ident.

## Audio direction
- Role: sparse professional accents; no music bed (5s is too short for a bed, silence between hits is the aesthetic)
- Music: none (intentionally silent bed)
- SFX posture: sparse — key ticks for typing, soft ticks per rule reveal, one dry impact hit on lockup
- Audio-coupled moments: typed hook line; 3 rule reveals; final hit
- Restraint rule: no swell, no riser, no reverb tail past 5.0s
